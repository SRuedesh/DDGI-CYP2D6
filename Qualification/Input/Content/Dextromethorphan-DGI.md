The Dextromethorphan DGI evaluation uses the `Dextromethorphan-Model` parent model source. It includes CYP2D6 activity-score comparisons for dextromethorphan and dextrorphan from Capon 1996, Gorski 2004, Qiu 2016, Storelli 2018, and Yamazaki 2017.

The available DGI ratio mappings include the following endpoints:

| Endpoint | Evidence |
| --- | --- |
| Dextromethorphan | Five study-specific activity-score comparisons |
| Dextrorphan | One activity-score comparison |

The scientific check is study-specific parent-metabolite consistency. Higher CYP2D6 activity is expected to reduce dextromethorphan exposure and to alter dextrorphan formation. Differences in dose, formulation, and activity-score grouping preclude pooling these studies into a single exposure-response trend.
